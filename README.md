# Программ Хангамжийн Хөгжүүлэлт. Төсөл №2 

2025 оны хичээлийн жилийн Намрын Улиралд миний бие нь Программ Хангамжийн Хөгжүүлэлт (ICSI402) хичээлийг сонгон судлахдаа Java программчлалын хэлийг ашиглан, Java Servlet болон JavaServer Pages технологийн тусламжтайгаар бүрэн ажиллагаатай Quiz App Веб Аппликейшнийг хөгжүүлж, Java хэлний веб технологийн талаар олон төрлийн шинэ мэдлэг, ур чадварыг эзэмшлээ. 

Уг веб төслийн хүрээнд миний бие нь өмнөх desktop application –ний үед гаргасан хөгжүүлэлтийн асуудлуудыг шийдэж, Database болон Аппликейшний уялдаа холбоог улам сайжруулсан бөгөөд нэмэлтээр JavaServer Pages болон Java Servlet зэрэг технологиудыг ашиглаад амжилттай Java Web Application –ийг хийж гүйцэтгэлээ.
